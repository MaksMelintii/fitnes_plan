МІЙ ФІТНЕС-ПЛАН — ВСТАНОВЛЕННЯ НА ANDROID

Це легкий вебзастосунок (PWA), який можна додати на головний екран Android і відкривати майже як звичайну програму.

ЩО Є ВСЕРЕДИНІ
- План на 12 тижнів із завданнями на кожен день.
- Відмітки виконаних вправ, таймер відпочинку.
- Прогрес і записи ваги та талії.
- Збереження даних у браузері та експорт резервної копії.
- Після першого завантаження основна сторінка кешується для офлайн-відкриття.

ЯК ВСТАНОВИТИ НА ТЕЛЕФОН
Для встановлення PWA потрібна HTTPS-адреса. Найпростіший шлях:
1. Розпакуй ZIP на комп'ютері.
2. Створи репозиторій на GitHub і завантаж у нього index.html, manifest.webmanifest та sw.js.
3. У GitHub відкрий Settings → Pages.
4. У Source вибери Deploy from a branch, гілку main і папку /(root), натисни Save.
5. Дочекайся появи HTTPS-посилання на сайт.
6. Відкрий це посилання на Android у Chrome.
7. Меню ⋮ → «Установити програму» або «Додати на головний екран».

ВАЖЛИВО
- Дані зберігаються локально в браузері цього телефона. Не очищай дані сайту/браузера без резервної копії.
- Для перенесення даних скористайся вкладкою «Правила» → «Експортувати резервну копію».
- Це не APK з Google Play, а встановлюваний вебзастосунок. Потрібна публікація на HTTPS-хостингу.
